# CGPA-Calculator
A simple and responsive CGPA Calculator that helps students calculate GPA and CGPA with ease. Built using [HTML, CSS, JavaScript].
The CGPA Calculator is a lightweight web application designed for students to easily compute their semester GPA and overall CGPA. 
Users can enter course details such as subject names, credit hours, and grades to get instant results. 
The project is built with a clean user interface and focuses on accuracy and simplicity.
